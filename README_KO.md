# ClipForge 웹사이트 V1 — 실행 및 교체 안내

이번 ZIP은 ai-free-tools.com을 ClipForge 브랜드로 교체하기 위한 **완전한 정적 웹사이트 소스**입니다. 현재 GitHub 원본을 덮어쓰기 전에 반드시 백업하세요.

## 직접 확인하기

- PC에서는 `index.html` 파일을 열어 디자인을 볼 수 있습니다.
- **샘플 비디오와 편집 기능을 제대로 테스트하려면 로컬 웹서버 또는 Vercel 배포가 필요합니다.** `file://`로 열면 브라우저 보안 때문에 샘플 영상 읽기가 실패할 수 있습니다.
- 윈도우에서 Python이 있다면 압축 푼 폴더에서 명령 프롬프트에 `python -m http.server 8000`을 실행하고 `http://localhost:8000/`에 접속하세요.
- 사이트가 정상적으로 뜨면 `Studio` → `Try sample clip` → 0~3초 IN/OUT → Add clip → Render & export로 테스트할 수 있습니다.

## 구현되어 있는 실제 기능

- 메인 소개/스토디오/자체 작성 가이드 4개/소개/문의/개인정보/이용약관 등 **정적 페이지**
- 로컬 영상 파일 열기, 샘플 비디오 열기, 미리보기 재생/탐색
- 선택한 영상의 여러 구간을 등록, 순서 변경, 삭제
- 세로(9:16) · 정사각(1:1) · 가로(16:9) 화면, Blur+fit / Fit / Fill
- 확대 및 수평 포커스, 제목/색상/위치/글자 크기
- 브라우저 Canvas + MediaRecorder를 사용한 **실제 영상 내보내기**. MP4가 가능한 브라우저는 MP4, 아니면 WebM 다운로드
- 120초까지 내보내기 제한. 내보내는 길이와 거의 같은 시간만큼 브라우저가 실시간 인코딩함.
- 영상의 픽셀/오디오는 사이트 서버에 업로드하지 않음. 가입·DB·API 호출 없이 작동.

## 아직 없는 기능 (절대 완성된 것처럼 홍보하지 않음)

- AI 하이라이트 자동 탐지 (과거 테스트에서 잘못된 장면이 선택되던 문제 있음)
- 음성 자동 인식 자막, SNS 자동 업로드, 회원가입/게시판, 다른 동영상 파일끼리 병합
- 모든 브라우저에서 MP4 강제 출력 (브라우저가 미지원하면 WebM임)
- 서버측 백그라운드 변환, 워터마크 없는 내보내기는 있으나 기기의 처리 성능에 종속됨.

## GitHub / Vercel 교체 절차

1. 현재 `zotdd/my-ai-tools` 저장소를 먼저 ZIP으로 백업하고 새 브랜치에서 작업하세요.
2. 사이트 파일은 **ZIP 안의 `ClipForge_Web_V1/` 폴더 내부 파일**을 웹 루트에 올리세요. `build_pages.py`, `create_demo.py`는 빌드 원본이므로 올리지 않아도 됩니다.
3. **예전 `/api/*.js` 파일, 홍보 페이지 등을 그대로 남기지 마세요.** 이전 사이트 경로가 남아 있으면 구 콘텐츠가 계속 노출됩니다. 필요하다면 옛 주소에 대해 301을 새 주소로 구성하세요.
4. Vercel을 기존 GitHub 저장소에서 배포하고 `ai-free-tools.com` 연결 상태를 확인하세요.
5. Studio에서 실제 자신의 MP4 파일과 샘플로 영상 편집/음성/다운로드를 확인하세요.
6. 모바일 화면, 문의 이메일 수신, sitemap.xml, privacy 및 terms, 검색 링크를 점검하세요.
7. 콘텐츠가 실제로 유용하고 정합적인지 확인한 뒤 애드센스 재검토 요청을 검토하세요. **승인을 보장하지 않습니다.**

## 기술적 주의

- Chrome/Edge 같은 데스크톱 브라우저에서 가장 잘 동작하도록 설계했습니다.
- 영상이 MP4여도 브라우저 지원 코덱이 아니면 로드할 수 없습니다.
- MediaRecorder가 제공하는 실제 형식만 사용하며 WebM을 MP4 확장자로 속여 저장하지 않습니다.
- 오디오와 이어붙인 구간 경계는 코덱에 따라 차이가 날 수 있으므로 실제 파일을 꼭 확인하세요.
- 장시간/고해상도 영상은 브라우저가 멈출 수 있습니다. 짧은 쇼츠 편집에 사용하세요.
- 녹화 동안 다른 탭으로 이동하지 않는 것이 좋습니다.
- 코드에는 개인 API 키나 서버 시크릿을 포함하지 않았습니다.
