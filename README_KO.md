# ClipForge 웹사이트 V1.1 — 실행 및 교체 안내

이번 ZIP은 ai-free-tools.com을 ClipForge 브랜드로 교체하기 위한 **완전한 정적 웹사이트 소스**입니다. 현재 GitHub 원본을 덮어쓰기 전에 반드시 백업하세요.

## 직접 확인하기

- PC에서는 `index.html` 파일을 열어 디자인을 볼 수 있습니다.
- **샘플 비디오와 편집 기능을 제대로 테스트하려면 로컬 웹서버 또는 Vercel 배포가 필요합니다.** `file://`로 열면 브라우저 보안 때문에 샘플 영상 읽기가 실패할 수 있습니다.
- 윈도우에서 Python이 있다면 압축 푼 폴더에서 명령 프롬프트에 `python -m http.server 8000`을 실행하고 `http://localhost:8000/`에 접속하세요.
- 사이트가 정상적으로 뜨면 `Studio` → `Try sample clip` → 0~3초 IN/OUT → Add clip → Render & export로 테스트할 수 있습니다.

## 구현되어 있는 실제 기능

- 메인 소개/스토디오/자체 작성 가이드 6개/소개/문의/개인정보/이용약관 등 **정적 페이지**
- 로컬 영상 파일 열기, 샘플 비디오 열기, 미리보기 재생/탐색
- 선택한 영상의 여러 구간을 등록, 순서 변경, 삭제
- 세로(9:16) · 정사각(1:1) · 가로(16:9) 화면, Blur+fit / Fit / Fill
- 확대 및 수평 포커스, 제목/색상/위치/글자 크기
- 브라우저 Canvas + MediaRecorder를 사용한 **실제 영상 내보내기**. MP4가 가능한 브라우저는 MP4, 아니면 WebM 다운로드
- 120초까지 내보내기 제한. 내보내는 길이와 거의 같은 시간만큼 브라우저가 실시간 인코딩함.
- 영상의 픽셀/오디오는 사이트 서버에 업로드하지 않음. 가입·DB·API 호출 없이 작동.

## 아직 없는 기능 (절대 완성된 것처럼 홍보하지 않음)

- AI 하이라이트 자동 탐지 (과거 테스트에서 잘못된 장면이 선택되던 문제 있음)
- 음성 자동 인식 자막, SNS 자동 업로드, 회원가입/게시판, 다른 동영상 파일끼리 병합
- 모든 브라우저에서 MP4 강제 출력 (브라우저가 미지원하면 WebM임)
- 서버측 백그라운드 변환, 워터마크 없는 내보내기는 있으나 기기의 처리 성능에 종속됨.

# ClipForge Web V1.3 — 하단 텍스트 + DeepSeek Vision 베타

## 추가한 내용

1. 기존 메인 타이틀과 **독립적으로** 화면 하단 텍스트를 입력하고 폰트 크기 및 색상 조절. 두 문구가 동시에 미리보기 및 출력에 포함됩니다.
2. **DeepSeek Vision**: 사용자가 정한 `Clip start` ~ `Clip end` (5~90초) 범위에서 4~12장의 저해상도 정지 프레임을 브라우저에서 JPEG로 샘플링합니다. 전송 동의 후 DeepSeek Flash 모델로 분석해, 대략적인 후보 구간 최대 3개를 제공합니다. 사용자는 각 후보를 편집 목록에 수동으로 추가할 수 있습니다.
3. 기존 무료 수동 편집·렌더 기능은 **API 연결 없이도 사용 가능**합니다.

**중요한 기술적 한계:** 이것은 영상을 30fps로 끝까지 보는 AI가 아닙니다. **정지 프레임 4~12개**만 보내므로 빠른 액션이나 인터뷰의 말 내용, 오디오를 이해하지 못합니다. 예전에 롤 게임에서 죽은 상태를 하이라이트로 뽑는 오류를 해결했다고 주장할 수 없습니다. AI 후보는 반드시 사람이 확인·수정해야 합니다.

## 반드시 설정할 환경 변수 — Vercel

1. Vercel Dashboard → `my-ai-tools` → Settings → Environment Variables.
2. `DEEPSEEK_API_KEY` = 본인의 **DeepSeek API 키** (챗GPT/OpenAI 키 **아님**). 프로젝트 환경 변수에 저장, 깃허브 파일에는 절대 기록 금지.
3. `CLIPFORGE_AI_ACCESS_CODE` = 사이트 운영자만 아는 **긴 임의 코드**. AI 분석 화면의 Private beta access code 칸에서 입력. 테스트 중 방문자가 코드를 모르면 DeepSeek 분석을 실행할 수 없으므로 잔액 보호에 도움이 됩니다.
4. Production (필요하면 Preview) 적용 후 기존 프로젝트에서 **Redeploy**. 새 변수는 배포에 반영되어야 작동합니다.
5. `studio.html`에서 비디오 불러오기 → `Clip start`와 `Clip end`로 5~90초 구간 지정 → 접근 코드 입력 → 프레임 전송 동의 → Analyze chosen range. 결과가 나오면 `+ Add clip` 선택.

**주의:** 현재 보호는 베타 접근 코드 + 인스턴스 단위 속도 제한뿐입니다. Vercel 서버리스의 인스턴스별 제한은 전체 서비스 비용 한도를 보장하지 않습니다. 다수 사용자를 위한 공개 AI 기능에는 지속형 사용량 제한/인증을 구축하고 지출 한도를 별도로 관리해야 합니다. **이 버전을 공개 테스트할 때는 AI 접근 코드를 외부에 공개하지 마세요.** 

API 키 또는 DeepSeek 잔액이 없으면 AI 버튼은 실패 메시지를 표시하지만 무료 수동 편집은 정상 작동합니다. OpenAI/ChatGPT API에 대한 호출은 **코드에 전혀 없습니다**.

### 개인정보
기본 비디오 파일은 로컬에서만 처리되지만, AI 분석을 **명시적으로 선택하면 샘플 JPEG 프레임만** ClipForge 서버를 거쳐 DeepSeek에 전송합니다. 전체 영상·오디오는 보내지 않습니다. 개인정보 처리방침에 반영했습니다. 민감한 영상에는 AI를 사용하지 않는 것이 좋습니다.

### 배포
이 전체 ZIP의 내용으로 현재 `my-ai-tools` 폴더의 웹파일을 덮어씁니다. **`.git` 폴더는 지우지 마세요.** GitHub Desktop에서 Commit to main → Push origin. Vercel에 환경 변수를 설정하고 재배포합니다. `api/deepseek-highlights.js`도 함께 커밋되어야 합니다.

### 확인 순서
1. 9:16 미리보기에서 상단 타이틀+하단 텍스트 동시 표기.
2. 5초 클립 MP4/WebM 내보내기 및 자막 위치.
3. 접근 코드 오류/누락 상태에서 AI 요청 차단.
4. 올바른 DeepSeek 키와 코드 설정 후 선택한 5~90초 프레임 분석.
5. `+ Add clip`으로 후보를 등록해 실제 내보내기.

### AdSense 준비
하단 텍스트와 AI 연결만으로 승인을 보장하지 않습니다. 사이트 콘텐츠, 서비스 기능의 실제 작동 여부, 문의 주소의 수신 가능 여부, 광고 정책/개인정보 고지, 모바일 사용성을 검사한 후 재심사를 신청하세요. 기존 ads.txt 게시자 ID가 **본인 것인지 꼭 확인**하세요.
